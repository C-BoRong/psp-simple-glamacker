# PSP 功能界面风格指南

先选方向。**XMB** 使用本模板的菜单、存读档和鉴赏布局；**复刻目标游戏**使用用户指定的参考，保留该作的信息顺序、窗口、图标和选中态。可以混用，例如原标题与对白、XMB 功能页。把每页的选择记录在移植计划中。参考截图不是要放进 ISO 的整页图片。

## XMB 的视觉语法

以 ATRI PSP 移植版 `ui_menu`、`ui_slot`、`ui_save_preview`、`ui_gallery_sheet` 为参照。480×272 画布上，以当前场景为底，叠半透明蓝幕、暗部渐变和低对比波纹。浅白正文、灰蓝次要文字；主题强调色只标当前焦点与细线。避免大面积实心选择条淹没背景。正文沿用思源黑体 Bold 大陆字形。

| 页面 | 构图与交互 |
|---|---|
| 主菜单 | 活动分类靠 x≈120；横向按约 92 px 排列。当前行靠 y≈150，以空心菱形标记，行距 30 px。左右切分类，上下切项目。只列能工作的功能。 |
| 存档与读取 | 页标题在 (28,20)，两道水平分隔线在 y≈49、236。左列显示编号，当前槽居中；右侧为 216×122 的真实场景预览，空槽显示「暂无预览」。缩略图只捕获剧情，不捕获菜单。重复写入先确认，写入失败要显示。 |
| 鉴赏 | 编号和总数弱化；图片保留原比例，图名独立占一行。左右切换、○ 全屏、× 逐层返回。不要把截图做成按钮或将所有原图一起载入内存。 |
| 弹窗 | 只阻挡必要操作。短句说明动作及后果；取消保留原选项；成功、空槽、不可读与写入失败不可混用。 |

功能界面实际使用 `runtime/atri-ui/ui.c`、`ui_motion.c` 和 `gallery.c` 的原版绘制。菜单使用动态波纹、模糊、焦点与页面切换；存档页调用 `ui_slot` 与 `ui_save_preview`。鉴赏按上下选组、左右跳组，○ 打开；查看时 ○ 切换放大，摇杆平移，× 返回。模板接入十个手动槽和公开图集，没有开启原游戏的自动／快速槽或剧情解锁。`tools/atri_ui.py` 在构建目录绑定项目菜单标签和数量，并生成字体及图集资源。请用实际 ISO 查看，不要重新实现静态菜单作为替代。

## 复刻目标游戏的工作方法

请用户可选地提供同一场景下关闭菜单、打开菜单、选中/未选中、满槽/空槽、覆盖确认和鉴赏大图。记下原图尺寸、地区语言、素材标识和参考状态。先拆分背景、面板、游标、字体与文字；标记哪些来自素材、哪些需绘制。保留嵌入图像的字体，移植正文按 PSP 可读性重新排版。在 480×272 上做一页交互样板，展示与原图的裁切、字宽和输入差异，由用户确认再扩到其他页面。缺少参考时标注推测。

验收至少覆盖：长标题、边界槽、空槽、取消覆盖、保存后重启再读取、选项光标恢复、鉴赏首尾切换与全屏返回。开发预览看布局；模拟器检查按键与状态；真机单独测存储失败、写入停顿、字形可读性和翻页时间。
