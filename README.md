#psp-simple-glamacker

想把喜欢的文字冒险游戏带到 PSP 上玩？你可以用中文告诉 AI 助手（agent）想移植哪部作品、想保留什么，再拿到一份能试玩的 PSP 游戏文件（`.iso`）。你负责选素材、做决定、说出试玩感受；助手负责检查工具、处理素材和制作游戏。你不需要写代码。

## 我能做出什么？

- **有对白和分支的故事。** 玩家可以阅读中文对白，在选项中做决定，走向不同结局。
- **有自己风格的游戏。** 你可以选 PSP 游戏列表里的封面和背景，也可以选游戏里的场景图和背景音乐。功能菜单可以沿用 ATRI 移植版的半透明蓝色菜单，也可以提供原游戏截图，让助手按参考图制作，再由你看效果。
- **能保存进度、浏览插画的版本。** 模板自带十个手动存档位、读档和画面鉴赏。你可以告诉助手要保留哪些功能。

每部游戏使用的文件都可能不同。助手会先做一小段给你玩，确认对白、画面、选择和存档都符合预期，再继续制作其他章节。遇到特殊动画或暂不支持的功能，它会告诉你哪里需要另外处理。

## 第一次使用：照着这四步走

1. **打开项目，说「开始」。** 在 Windows 电脑上，用你的 AI 助手打开包含这份 README 的**整个文件夹**，然后在聊天框输入 **开始**。如果它没有进入引导，就说：「请先读这个文件夹里的 AGENTS.md，然后带我开始移植。」
2. **选谁试玩，告诉它作品名。** 助手会先问你想自己手动测试，还是让它自动测试，再帮你检查电脑。你可以直接回答：「我自己试玩。我想移植《作品名》的简体中文版，先做到第一个选项。」如果电脑缺少工具，按助手提示处理即可。
3. **放入游戏素材。** 打开项目里的 `inputs` 文件夹，再打开 `original`。把原游戏**解包后的文件和子文件夹**放进去，保持原来的名字和目录结构，然后回复「放好了」。如果你手里只有安装包，不确定该放什么，就告诉助手你有哪些文件，不用猜。
4. **选样式，试玩第一段。** 助手会结合已有素材让你选封面、背景、音乐和菜单。比如你可以说：「用蓝色菜单，保留存档和鉴赏；对白框照这张截图做。」第一段做好后，助手会告诉你 `.iso` 文件在哪里。想调整时直接描述看到的问题，例如：「第一组选项的第二行被截断了。」确认满意后，再让它继续下一章。

每完成一项任务，助手都会告诉你**现在做到哪里、接下来还剩什么**。下次打开同一项目，说「继续」即可。

## 只想先看看效果？

不用准备自己的素材。项目里有一个叫《末班电车》的小故事，含两个结局。在 PSP 模拟器 **PPSSPP** 中打开项目 `dist` 文件夹里的 **`HOME00001.iso`** 就能试玩。没有找到文件时，直接对助手说：「请帮我生成《末班电车》的试玩版，并告诉我怎么打开。」

试玩时，按 **○** 推进对白或确认，用**上下方向键**选答案，按 **START** 打开菜单，按 **×** 返回。你可以在第一个选项前存档，选一条路，再读档试试另一条。
